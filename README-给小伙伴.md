# 快乐小事 · 拿去变成你自己的

一个纯前端的「快乐记录」小站：记好事、快乐广场、哈哈机、坏情绪粉碎机、问观音灵签、天气指数、快乐花园。

零后端、零依赖、断网也能跑。你拿到的这份源码，改几处就能变成你自己的。

---

## 一、最快：不下载，直接用

打开在线版，手机浏览器菜单里点「添加到主屏幕」，就是一个 App 图标。

⚠️ **一句话说清数据**：所有记录存在**你自己手机的浏览器里**（按账号分开存），不在服务器上，也不上传。换设备、换浏览器、清缓存 = 数据不会跟过来。应用里有导出备份入口，建议定期导出。

## 二、下载源码

**方式 A（不用装 git）**

1. 打开仓库页面
2. 点绿色的 `< > Code` 按钮
3. 点 `Download ZIP`
4. 解压

**方式 B（装了 git）**

```bash
git clone https://github.com/le4535441-star/happy-diary.git
```

## 三、先在本地跑起来看看

⚠️ **不要双击 `index.html` 打开**。这个应用用了 Service Worker（离线缓存），`file://` 协议下注册不了，会白屏。

在解压后的目录里起一个静态服务：

```bash
cd happy-diary
python3 -m http.server 8000
```

浏览器打开 http://localhost:8000

（没有 python 也行：`npx serve`，或用 VS Code 的 Live Server 插件）

## 四、变成你自己的（三步）

### 第 1 步 · 部署成你自己的网址

1. 在 GitHub 上 **Fork** 这个仓库（右上角 Fork 按钮），或新建空仓库把文件传上去
2. 进你自己的仓库 → `Settings` → `Pages`
3. `Source` 选 `Deploy from a branch`，分支选 `main`，目录选 `/ (root)` → Save
4. 等 1-2 分钟，就得到你自己的网址：`https://<你的用户名>.github.io/<仓库名>/`

🔴 **Fork 之后必须改一处**：如果你自己的仓库名不叫 `happy-diary`，打开 `manifest.json`，把这两行改成你的仓库名：

```
"start_url": "/happy-diary/index.html",
"scope": "/happy-diary/",
```

改成 `/你的仓库名/index.html` 和 `/你的仓库名/`。不改的话，加到手机桌面后点开是 404。

### 第 2 步 · 改名（可选）

| 想改什么 | 改哪里 |
|---|---|
| 手机桌面上的名字 | `manifest.json` 的 `name` / `short_name`；`index.html` 第 8 行 |
| 浏览器标签页标题 | `index.html` 第 14 行 |
| 登录页大字 | `index.html` 第 2477 行 |
| 登录页小字 slogan | `index.html` 第 2679、2687 行 |
| 桌面图标 | `manifest.json` 里的 `icons`，现在是 📖 这个 emoji，换个 emoji 就行 |

### 第 3 步 · 决定数据存在哪（重要）

默认配置里，云同步连的是**原作者**的云开发环境。也就是说，如果你什么都不改就注册账号，你的记录会存到那个环境里。想让数据完全归自己，三选一：

**① 纯本地（最省事，推荐先这么玩）**

把 `index.html` 第 11 行这一句注释掉：

```html
<!-- <script src="cloudbase.bundle.js"></script> -->
```

程序检测到没有云 SDK，会自动切成纯本地模式：注册、登录都在你自己的浏览器里完成，数据只存在本地，完全不外传。代价是没有多设备同步。

**② 用自己的云同步（想要多设备同步才需要）**

1. 去腾讯云 CloudBase 建一个环境（有免费额度）
2. 在控制台开通「邮箱登录」
3. 把 `index.html` 里 3 处的环境 ID 换成你自己的：第 3775、6721、8326 行
   ```js
   cloudbase.init({ env: '你的环境ID' })
   ```

**③ 什么都不改**

能用，但你的记录会存在原作者的云环境里。不建议。

## 五、改完代码记得两件事

1. **升 Service Worker 版本号**：`sw.js` 第 1 行 `happy-diary-cloud-v181`，把 `v181` 改成 `v182`。不升的话，打开过旧版本的人会一直看到缓存里的旧页面。
2. **手机上清一次缓存再试**，或者换个浏览器测。

## 六、常见问题

**换手机了，数据能跟过来吗？**
纯本地模式下不能。应用里有「导出备份」，导出 JSON，在新设备上导入。

**能改成别的语言吗？**
界面文字都在 `index.html` 里，直接改就行，没有单独的语言文件。

**「每周小诗」用不了？**
那是个可选的云函数，需要自己的云开发环境 + 一个大模型 API Key。不装不影响其它功能。

**华为手机加到桌面后不是全屏？**
华为自带浏览器不支持 PWA 全屏，用 Chrome 打开再添加。

## 七、目录说明

| 文件 | 是什么 |
|---|---|
| `index.html` | 全部页面与逻辑（单文件，没有构建步骤） |
| `sign-data.js` | 观音灵签 100 签的签文数据 |
| `signs/*.gif` | 签文配图 |
| `sw.js` | Service Worker，离线缓存 |
| `manifest.json` | PWA 配置（桌面图标、名字） |
| `garden-bg.jpg` / `welcome.*` | 快乐花园底图与开场素材 |
| `cloudbase.bundle.js` | 云同步 SDK（纯本地模式可以不要） |
| `cloudfunctions/` | 可选的「每周小诗」云函数 |
